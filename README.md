Tuesday's World News Front Page: 49 sourced stories, 7 regions — a 1024×1024
newspaper front page summing up Tuesday 24 November 2026.

Hero: Nvidia reinstates Jensen Huang as CEO, 11 days after he quit — Trump
says "I made the deal", shares +31%. Below the hero: 49 sourced stories
across North America, Europe, the Middle East, Asia-Pacific, Africa, Latin
America and Sport & More, a UTC timeline, a numbered world map (14 places),
a DATE CHECK box naming stories that recirculated today but did NOT happen
on 24 Nov (ICJ Myanmar ruling, Trump–Xi–Putin summit, Kerch Bridge strike,
Fiona the hippo), and an ALSO TODAY strip. Every story on the page carries
its source, and stories dated 21–23 Nov are flagged with their true date.

`main.py` is pure Python standard library: it renders the page from data
embedded in the program (bitmap glyph tables decoded at run time, no
network, no timestamps) and writes one deterministic PNG to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`).

## Run it

```sh
python3 main.py
```
